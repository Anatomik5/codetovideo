# CTV · CodeToVideo (кратко по-русски)

> Это краткий перевод. Он может отставать от [английского README](../../README.md), который является источником истины. За подробностями, таблицами флагов и актуальным статусом идите туда.

**Даёшь веб-приложение и одно предложение — получаешь промо-ролик. ИИ — режиссёр, программа — настоящая. Бесплатно, локально, без звука.**

## Зачем это

1. **ИИ галлюцинирует, когда генерирует видео:** выдумывает кнопки и экраны, которых нет.
2. **Я не умею монтировать** и не хочу учить таймлайны ради показа своего продукта.
3. **Инструменты, которые делают красивое демо по коду, платные.**

Поэтому в CTV ИИ только **планирует** (сцены, заголовки, подписи, темп, цвета), а всё, что видно на экране, — **реальная запись твоего реального приложения** (Playwright), которую собирают FFmpeg и Remotion. Выдумать там нечего.

Подключается **любая LLM с OpenAI-совместимым API**: бесплатный ключ или небольшая модель на своём компьютере. Я делал на **Ollama + `qwen3.5:4b`** (слабая 4B-модель, мне хватило) и также запускал с **Gemini 2.5 и 3.5** через их OpenAI-совместимый API — тоже работало.

**Всё работает локально, в том числе в закрытой среде:** с локальной моделью ничего не уходит с вашего компьютера, так что демо и промо для внутреннего или закрытого приложения можно делать офлайн, даже на маленькой модели. Лицензия MIT: пользуйтесь бесплатно, меняйте и делитесь.

## Быстрый старт

Нужен Node.js 20+ (лучше 22). Для бесплатного локального варианта — [Ollama](https://ollama.com).

```bash
git clone https://github.com/Anatomik5/codetovideo.git
cd codetovideo
npm install
ollama pull qwen3.5:4b
npm run app
```

Windows: двойной клик по `start-app.vbs` (без окна консоли). В приложении выбери **Ollama (local, free)**, модель `qwen3.5:4b`, ключ оставь пустым. Запускать Ollama вручную не нужно.

Попробовать без своего проекта — встроенное мини-приложение:

```bash
npx ts-node scripts/demo-pipeline.ts --file examples/hello-wizard/server.js --upload examples/hello-wizard/sample.csv --model "qwen3.5:4b" --base-url "http://localhost:11434/v1" --prompt "Покажи весь путь от загрузки до экспорта, на русском"
```

## Что умеет

- Два формата: `demo` (обзор с анимированным фоном) и `promo` (корпоративная реклама: камера, врезки из настоящей записи, подписи по словам). Без звука.
- Качество от 480p до 4K (`--quality`), реально чётче на высоких значениях.
- Фон: `--backdrop auto | generate | motif` (модель рисует сама / модель только выбирает мотив).
- Правка одной сцены без пересъёмки остальных (`--edit-scene`, `--edit-prompt`, `--re-render-only`).
- Язык титров берётся из промпта; смысл кнопок («вперёд», «назад», «справка») определяет LLM по подписи, без списков слов в коде.

## Честный статус

**CTV — alpha.** Проверено на Windows 11, Ollama + `qwen3.5:4b`, Gemini 2.5 и 3.5 (собственные запуски автора), одном реальном приложении и встроенном примере. На macOS и Linux, на других провайдерах и на большинстве реальных приложений — не проверялось. Навигация эвристическая: логины, drag-and-drop, canvas, iframe, вероятно, не пройдёт. Remotion — не чистая MIT-лицензия (см. [THIRD_PARTY.md](../../THIRD_PARTY.md)). Подробнее: [английский README, Honest status](../../README.md#honest-status).

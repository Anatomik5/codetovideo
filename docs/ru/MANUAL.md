## 1. Установка (один раз)

1. Установи **Node.js 20+** (лучше 22) (<https://nodejs.org>).
2. *(Бесплатная локальная модель)* Установи **Ollama** (<https://ollama.com>), затем в терминале: `ollama pull qwen3.5:4b`.
3. В папке проекта выполни `npm install` (скачает Electron и Chromium, несколько минут).

## 2. Запуск

- Windows: двойной клик по `start-app.vbs` (без окна консоли)
- macOS / Linux: `./start-app.sh`
- Везде: `npm run app`

## 3. Подключение модели

В блоке **Model**:

| Что используешь | Provider | Пример модели | API key |
| --- | --- | --- | --- |
| Локальная Ollama | Ollama | `qwen3.5:4b` | пусто |
| Google Gemini | Google Gemini | `gemini-2.5-flash` | твой ключ |
| OpenRouter | OpenRouter | `openrouter/free` | твой ключ |
| Любой другой OpenAI-совместимый | Custom URL | имя модели | ключ, если нужен |

Для Ollama список моделей подставляется сам. Если Ollama не запущена, CTV запустит её сам.

## 4. Создание видео

1. **Source** — выбери *одно*:
   - **Folder / File**: твой проект (или файл запуска, например `dev.py`). CTV сам запустит приложение и найдёт его адрес.
   - **URL**: уже запущенное приложение, например `http://localhost:3000`.
2. **Files to upload** — если приложению нужны файлы (таблица, JSON…), добавь их **в том порядке**, в каком приложение их запрашивает.
3. **Theme** — `auto` повторяет стиль самого приложения.
   **Format** — *Demo walkthrough* или *Corporate promo* (рекламная подача: движение камеры и врезки, без звука).
   **Background** — кто делает фон демо: модель рисует сама, модель выбирает готовый мотив (быстро) или авто.
   **Quality** — от 480p до 4K. Выше — чётче, но запись и рендер дольше; 720p — хороший вариант по умолчанию.
4. **Prompt** — опиши видео (подсказки ниже).
5. Нажми **Generate video**. Следи за **Log**; ролик около минуты делается несколько минут. **Stop** отменяет.

Готовое видео появится в **Output**; **Show in folder** откроет папку (`out/demo.mp4`).

### Подсказки для промпта

Пиши своими словами, на любом языке:

- **Сценарий:** «покажи весь путь от загрузки до экспорта».
- **Язык титров:** «заголовки и подписи на английском» / «на русском».
- **Темп:** «прокручивай медленно», «давай каждому экрану время» → медленнее скролл и дольше пауза.
- **Стиль и фон:** «индустриальный стиль, на фоне строительный кран», «тёмный неон с линиями микросхем».
- **Что пропустить:** «не открывай страницу настроек».

Коротко и конкретно лучше, чем длинно и размыто.

## 5. Правка видео

Открой вкладку **Edit**: там список сцен последнего видео с заголовками и подписями.

1. Нажми на сцену.
2. Опиши изменение:
   - *текст / стиль:* «сделай заголовок Cost Breakdown», «подпись короче», «цвета теплее», «другой фон: …» — быстро, съёмка не повторяется;
   - *съёмка:* «пересними этот шаг и прокрути ниже до таблицы» — заново снимается только эта сцена.
3. Нажми **Apply edit**.

**Re-render only** пересобирает итоговое видео из сохранённых клипов (удобно после ручной правки `out/sessions/<id>/manifest.json`).

Правки всегда применяются к **самой свежей** сессии.

## 6. Где что лежит

| Что | Где |
| --- | --- |
| Итоговое видео | `out/demo.mp4` |

## 7. Если что-то не так

| Проблема | Что делать |
| --- | --- |
| «Model not found» в логе | `ollama pull <модель>` с точным именем из поля. |
| Долго ничего не происходит (Ollama) | Первый вызов загружает модель — подожди минуту. Проверь, что Ollama установлена (`ollama --version`). |
| «Could not detect a running web UI URL» | Укажи адрес приложения в поле **URL** или флаг `--port`. |
| Видео оборвалось раньше | В конце лога есть `stopReason`: приложению нужен ввод, которого у CTV нет (например, файл). Добавь файл в *Files to upload*. |
| Титры не на том языке | Укажи язык прямо в промпте. |
| Слабый рисунок фона | Нормально для маленьких моделей: CTV достраивает его сам; большая модель рисует лучше. |
| Правка не находит сцену | Правка идёт по самой свежей сессии; сгенерируй видео заново или выбери нужную сцену. |

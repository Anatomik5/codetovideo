# Code of Conduct

We want CTV to be a friendly place for people of every background and experience level.

**Be respectful.** Disagree with ideas, not with people. No harassment, personal attacks, discrimination, or unwelcome sexual attention.

**Be constructive.** Bug reports and critiques are welcome: be specific, be patient, assume good intent. Newcomers will ask basic questions; answer them kindly.

**Be safe.** Do not post other people's private information, secrets or API keys (yours included). Redact logs before sharing.

**Moderation.** Maintainers may edit, hide or remove comments, issues and contributions that break these rules, and may block repeat offenders. To report a problem, open a private security advisory on the repository or contact the maintainers through the address listed in the repository profile.

This policy applies to all project spaces: issues, pull requests, discussions and any official channel.
